# Night versions of the approved landmark set

Mended Drum, Archives, Market Hall, Lantern Row, Crypt and Storehouse, 19 November 2026.

Each night WebP has exactly the same dimensions and alpha bytes as its approved source in the parent folder. Use the same anchor and draw scale to swap or blend the sprites. Verification decodes the final encoded files and compares every alpha byte. Source and night hashes are recorded in manifest.json.

Lighting uses cool moonlight and warm existing windows and lanterns. The built-in image generator produced a lighting study for each approved building. Its soft illumination field was transferred onto the original approved pixels, preserving the original architectural detail and silhouette. These files are candidate art for review, awaiting game integration and in-game lighting checks.

Preview order is Mended Drum, Archives, Market Hall, then Lantern Row, Crypt and Storehouse.
