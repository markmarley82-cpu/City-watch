# Player recruit art review

Standalone WebP review sheets for three human appearances, plus the dwarf and troll. These use the existing character atlases for identity and the newer combat art for paint style.

Four rows, read left to right: idle, walk, unarmed strike, guard. These are review exports. The live atlases use a different layout and include other states and equipment variants. Check frame bounds, foot anchors, relative race scale, and equipment overlays before integrating.

These files are outside `dist/`; no runtime or deployment changes.
